# Vrinda_Store_Annual_Report_2022
Excel data analysis project on Vrinda Store's 2022 sales report featuring data cleaning, pivot tables, interactive dashboards, and business insights.

Vrinda Store Annual Report 2022 is an Excel data analytics project that analyzes the annual sales performance of Vrinda Store. The project includes data cleaning, preprocessing, pivot table analysis, and an interactive dashboard to visualize key business metrics such as:

Total sales
Monthly sales trends
Top-performing states
Sales by gender and age group
Order status analysis
Sales by sales channel
Customer insights

Tools Used:

Microsoft Excel
Pivot Tables
Pivot Charts
Slicers
Dashboard
Data Cleaning

Skills Demonstrated:

Data Analysis
Data Visualization
